# 인수인계: 정박 몫 예측 (기준선 비교 → 전용 모델)

작성 2026-10-12. 대상 작업: 순서 2(기준선 비교)와 3(정박 전용 분위수 모델). 둘 다 **아직 시작 전**이다.
순서 1(A-4 커밋: `evaluation/strict.py`, `experiments/A-4_trust_inputs/`, `tests/integration/test_strict_validation.py`, decisions.md 항목)은 별도 작업이며 이 문서의 전제다. 커밋이 안 되어 있으면 먼저 한다.

## 1. 왜 하는가
- 2026~2028 예측 표에서 정박 몫을 어떻게 보여줄지 정해야 한다. 지금은 정박 예측이 **없다** (해상 `fc_*`, 총 `fct_*` 두 모델만 있고 정박 전용 모델은 한 번도 학습한 적 없다).
- 정박 몫(kg/해리) = 총(`co2_per_nm_kg`) − 해상(`sea_eff_kg_nm`). 실제 값끼리는 정확히 성립한다.
- 비용 모듈과 CII 는 총예측만 쓴다. 정박 몫은 **표시용**이다. 프런트가 예측 칸에 정박 몫을 꼭 보여줘야 하는지는 **팀에 확인이 필요**하다 (미확인). 불필요하면 이 작업 전체를 하지 않고 "정박 몫은 실적 구간에서만 표시"로 끝낸다.

## 2. 이미 아는 것 (직접 측정한 값)
총예측 − 해상예측의 차이를 정박 예측으로 쓴 경우. `Sea marksmen\검증예측\검증예측_{해상,전체}효율.parquet` 를 (imo, 기간_년, 출발연도)로 합친 43,805쌍.

| 항목 | 값 |
|---|---|
| 차이가 음수인 쌍 | 0.8% |
| 정박분 중앙값 / 차이의 중앙값 | 13.3 / 16.9 kg/해리 |
| 차이의 MAE (1/2/3년 뒤) | 11.40 / 13.46 / 14.04 |
| 마지막 값 유지 MAE | 12.90 / 15.43 / 16.09 |
| 실제 정박분과의 상관 (차이 / 마지막 값) | 0.58·0.55·0.46 / 0.53·0.46·0.40 |
| 해상 예측 오차 중앙값 / 총 예측 오차 중앙값 | 21.1 / 23.2 kg/해리 |
| 구간 폭 | 정박분의 약 6배 → 쓸 수 없음 |

해석: 두 모델의 오차(약 21~23)가 정박분(약 13)보다 커서 차이값은 대략적 점 추정뿐이다. **정박 전용 모델이 이보다 나은지는 모른다.**

## 3. 순서 2 — 기준선 비교 (학습 없음)
목적: 정박분을 "예년 수준"으로 두는 가장 단순한 방식들이 어디까지 맞는지 본다.

비교할 예측 (모두 출발 연도 t 까지의 정보만 사용, 미래 누출 금지):
1. 마지막 값 유지: 정박분(t)
2. 최근 3년 평균 (보고된 해만, 최소 1년)
3. 선종 평균 쪽으로 당긴 값: 그 배 평균과 같은 선종·연도 평균의 가중 평균 (가중치는 그 배의 보고 연수로. `models/common/position.py` 의 `EmpiricalBayesPosition` 과 같은 원리. 필요하면 단순 수축 계수 하나로 시작)
4. 참고: 총−해상 차이 (위 2절 값)

평가:
- 쌍과 시험은 `evaluation/strict.py` 의 `TESTS` 와 같게: h=1 출발 2023·2024, h=2 출발 2022·2023, h=3 출발 2022. 비교 대상은 목표 연도의 실제 정박분 (kg/해리, 수준 차이 기준 MAE).
- 쌍 집합은 2절과 같게(해상·총 모두 있는 쌍) 맞춰야 숫자가 비교된다.
- 지표: MAE, 중앙 오차(치우침), 실제와의 상관, 선종별 MAE (`evaluation/strict.py` 의 `type_table` 모양 참고).
- 정박분이 0 이거나 음수인 배가 있는지 먼저 센다 (아래 4절 주의).

산출물: `experiments/A-5_berth/baselines.py` + 결과 CSV + 짧은 결론 (decisions.md 한 줄).

**판정:** 3년 평균(또는 수축)이 마지막 값을 눈에 띄게 이기고 정박 몫이 표시용이면 → 이 방식으로 `ResultTable` 에 정박 몫 열을 추가하는 정도로 끝낸다 (순서 3 불필요). 기준선이 약하거나 구간이 필요하면 순서 3.

## 4. 순서 3 — 정박 전용 분위수 모델 (순서 2 결과를 본 뒤에만)
기존 `models/forecast` 의 분위수 회귀를 정박 수준에 한 번 더 적용한다.

- 구조: `QuantileForecast(level, prefix, ...)` 가 이미 `level` 열 이름과 `prefix` 를 받는다 (`models/forecast/quantile_stage.py`). 정박 열(`berth_kg_nm`)을 스냅샷에 파생하고 `prefix: fb` 로 stage 를 하나 더 두는 것이 가장 작은 변경이다. `cii: false`.
- 계약: 새 열 `fb_h{1,2,3}_p{10,50,90}` 를 `contracts/tables.py` 의 `RESULT_TABLE` 에 추가(버전 올림, 선택 열 → `models/bundle.py` 의 `OPTIONAL_COLS`).
- **주의 1 — 로그 변화:** 지금 피처와 목표는 `ln(목표 연도 수준 ÷ 출발 연도 수준)` 이다 (`build_features`, `make_pairs`). 정박분이 0 이하인 배·연도에서는 정의되지 않는다. 대안: `ln(1+x)` 변환, 또는 수준 차이를 목표로 (이 경우 `delta_clip_bounds`, 분위수 폭 s 의 정의도 같이 확인). 이 선택이 이 작업의 핵심 설계 결정이다.
- **주의 2 — 학습 쌍 수와 보정:** 시험 절차(`strict_predictions`)는 보정 연도를 학습에서 뗀다. 정박분은 해마다 흔들려 쌍이 더 노이즈가 크다. 시드 0 한 번의 결과만 믿지 말고 시드 몇 개로 잡음 범위(해상 모델에서 평균 3e-3)를 같이 본다.
- **주의 3 — 합의 불일치:** 정박 전용 예측과 해상 예측(`fc_*`), 총 예측(`fct_*`)은 서로 더해지지 않는다. 표시 방식(정박만 따로 보이기 / 총 = 해상 + 정박으로 맞추기)을 팀과 정해야 한다. 총·해상을 이 모델로 다시 맞추는 방안(총 고정 + 정박 비율 모델)은 별도 설계이며 기존 `fc_*` 가 바뀐다 — 팀 합의 없이 하지 않는다.
- 비교 기준은 순서 2의 최선 기준선과 2절 차이값. 성공 기준은 MAE 가 최선 기준선보다 낮고, 80% 구간 포함률이 80% 근처이며, 구간 폭이 정박분의 몇 배 이내(2~3배)인 것. 이 수치는 임의로 정한 출발점이니 결과를 보고 조정한다.
- 테스트: 학습 없이 확인하는 단위 테스트(정박분 0 처리, 합계 관계, 한 척 = 전체 일치 규칙). `tests/integration/test_strict_validation.py` 와 `tests/integration/` 의 forecast 테스트를 참고.

## 6. 하지 말 것
- 푸시, 기본 설정(`config/default`) 변경, 프런트 연결은 별도 승인 없이 하지 않는다.
