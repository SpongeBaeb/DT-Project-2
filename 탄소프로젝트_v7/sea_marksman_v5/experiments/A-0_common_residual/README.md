# 공통 잔차 모델 (담당: 배성우)

팀의 모든 분석이 같이 쓰는 **"같은 조건이면 보통 이만큼 쓴다"** 기준과, 그 기준에서 벗어난 정도(잔차), 그리고 동급 대비 격차의 원인 분해입니다.

```bash
python 공통잔차/common_residual.py      # web_v2_package 폴더에서, 약 1분
```

- 입력: MRV 파이프라인 `mrv_merged.parquet` (`데이터생성코드/data_source.py`)
- 이번 실행 데이터: 2018 v275 ~ 2025 v60, 내용 해시 `b04c77ff`, 96,242행 (5,000GT 이상 등 조건 적용 후)

---

## 1. 이 모델이 답하는 질문

1. **이 배는 같은 조건의 배보다 거리당 CO₂를 얼마나 더 쓰나?** → 잔차, 판정값(z)
2. **동급보다 더 쓰는 만큼은 어떤 요인에서 나오나?** → 요인별 기여와 설명되지 않는 부분
3. **다른 분석이 쓸 하나의 기준** → 결과 표

## 3. 모델

**선종마다 따로, 2018~2025년 전 연도를 함께** 추정합니다 (13개 선종).

```
ln(거리당 CO₂) = 연도 효과 + 크기(ln, ln²) + 속력(ln, ln²) + 정박 비중 + 역내 비중 + ln(해상 시간)
                 + 선령 + 설계 효율 지표(종류별 값, 없음 표시) + 내빙 + 대체연료 (+ 로팩스 고속선)
```

| 설계 결정 | 이유 |
|---|---|
| 지표: 거리당 CO₂ | CII·팀 보고서와 같은 기준. 팀 결정 전 권장안이며 코드의 `METRIC` 한 줄로 바꿀 수 있음 |
| 전 연도 함께 추정 | 2025 한 해만 쓰면 작은 선종의 기울기가 불안정 (LNG선 정박 기울기 오차 ±0.74) |
| 설계 효율 지표 추가 | 잔차에 고칠 수 없는 설계 차이가 섞임 (상관 0.26~0.6). 값은 선종×종류 중앙값과의 차이로, 없으면 0과 "없음" 표시 |
| 해상 시간·역내 비중 추가 | 운항 형태에 따른 차이를 회귀가 직접 흡수 (군집으로 나누는 것보다 단순하고 효과 비슷) |
| 적재 제외 | 계수 ≈ 0, 넣어도 설명력 같음 |
| 속력의 대기 해석 | 중앙 속력에서의 탄력성이 0.1 이하인 선종은 속력 막대를 "대기 추정 (평균 속력)"으로 표시 |
| 오차는 배 단위 군집 오차 | 같은 배의 여러 해는 독립이 아님 |

## 4. 원인 분해

배·연도마다 **같은 선종·같은 해·같은 크기 4분위**를 동급으로 봅니다.

```
ln(실제) − ln(동급 기준값) = Σ 요인 기여 + 설명되지 않는 부분
요인 기여        = 계수 · (이 배 값 − 동급 중간 값)
설명되지 않는 부분 = 잔차 − 동급 잔차 중간값
```

- **막대 합은 항상 격차와 정확히 같습니다.** 최대 오차 4.4×10⁻¹⁶, 계산 오차 수준입니다.
- 막대마다 **오차(`se_*`)**가 있습니다. 화면에서는 |기여| < 2×오차인 막대를 흐리게 그리면 됩니다.

**예: MAGNIFICA (화학제품운반선, 2025)**
- 실제 376.0, 동급 기준 292.2, 같은 조건 예상 334.1 kg CO₂/해리
- 격차 +25.2%p

| 막대 | 기여 | 95% 범위 |
|---|---:|---:|
| 정박 중 배출 | **+11.8%p** | ±1.2 |
| EU 역내 항해 | +2.3%p | ±1.5 |
| 선령 | +2.1%p | ±0.4 |
| 내빙 선급 | +1.7%p | ±1.6 |
| 설계 효율 지표 | +0.9%p | ±0.2 |
| EU 해상 시간 | −0.9%p | ±0.3 |
| 크기, 대기 추정(속력) | −0.3%p | – |
| **설명되지 않는 부분** | **+7.6%p** | |

판정: 줄여 잡은 평균 +13.9%p, z = 1.56 → 점검 필요(z ≥ 2) 아님

## 5. 판정값 (줄여 잡은 평균)

```
배마다 여러 해 resid_c 평균 × k,   k = σ²_배 / (σ²_배 + σ²_해마다 / 보고 연수)
z = (줄여 잡은 평균 − 선종 중간값) / 선종 퍼짐
```

- 보고 연수가 적은 배는 선종 평균 쪽으로 더 줄여 잡습니다(k가 작음).
- 선종 표기가 바뀐 배는 마지막 해의 선종으로 한 번만 계산합니다.
- 2025년 보고 12,663척 중 z ≥ 2: **330척**

## 6. 검증

| 완료 기준 | 결과 |
|---|---|
| 막대 합 = 격차 | 통과 (최대 오차 4.4×10⁻¹⁶) |
| 기울기 오차 표시 | 모든 막대에 `se_*`, 모든 계수에 군집 오차 |
| 재현 스크립트 | `common_residual.py`, 출처 해시 기록 |
| 부호 점검 | 4건 걸림 (아래, 방현수 님 검토 요청) |

**시간 분할 검증**: 2023년까지로 선종별 상위 2.5%를 뽑고, 2024~2025 평균 잔차로 평가 (같은 262척 기준)

| 방법 | 다음 두 해에도 +10% 넘게 유지 | 다음 두 해 초과 (중앙값) |
|---|---:|---:|
| 한 해 잔차 | 66% | +17.8% |
| **줄여 잡은 평균** | **77%** | **+20.7%** |

**모델 비교** (같은 검증 방식)

| 모델 | 평균 R² | 연도 간 잔차 상관 | 한 해 잔차 유지 | 줄여 잡은 평균 유지 | 미래 초과 중앙값 |
|---|---:|---:|---:|---:|---:|
| 이전 방식 (설계·해상 시간·역내 없음) | 0.737 | 0.637 | 69% | 75% | +24.1% |
| 설계 지표만 추가 | 0.757 | 0.620 | 66% | 76% | +21.8% |
| **최종 (전부 포함)** | **0.761** | 0.619 | 66% | **77%** | +20.7% |

(모두 같은 262척 기준)

- 설명력이 오르고, 잔차의 연도 간 상관은 조금 내려갑니다. 배마다 늘 있던 차이 중 **설계 몫이 빠졌기 때문**이고, 의도한 변화입니다.
- 미래 초과 중앙값이 +24.1% → +20.7%로 줄어든 것도 같은 이유입니다. 고칠 수 없는 설계 차이가 판정에서 빠졌습니다.
- 어느 모델이든 **줄여 잡은 평균이 한 해 잔차보다 6~11%p 낫습니다.**

## 9. 한계

- 인과가 아니라 연관입니다. 요인 막대는 "이 요인이 다른 배는 대체로 이만큼 다르다"입니다.
- 대기 시간은 직접 관측하지 못합니다. AIS가 있으면 속력과 분리할 수 있습니다.
- 해상 시간에 따른 가중(박준재 님 결과)은 아직 넣지 않았습니다. 받으면 판정값 계산에 넣을 자리가 있습니다(`shrink`).
- 설계 효율 지표가 없는 배(종류 표시 없음)는 설계 몫을 빼지 못합니다.
